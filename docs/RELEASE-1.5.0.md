# 쎈Doc 1.5.0 — 로컬 AI 구조 검토

공문 목록의 애매한 단계를 검토하고 표·한글 자동 번호까지 정리합니다.

## 사용 순서

1. 텍스트 또는 HWPX를 열고 **공문 항목 정리**를 누릅니다.
2. 명확한 기호·번호는 바로 미리보기에 나타납니다. 애매한 항목은 직접 단계를 고르거나 **AI 구조 검토(선택)**를 실행합니다.
3. AI 제안을 골라 **AI 제안 미리보기에 반영**을 누릅니다. 이때 본문은 아직 바뀌지 않습니다.
4. 미리보기를 확인하고 **변경 사항 적용**, **교정본 저장**을 누릅니다. 원본 파일은 유지합니다. 적용한 내용을 한 번에 되돌릴 수 있습니다.

## 하네스

`src/ai/structure-harness.cjs`가 대상 분리, 셀 경계, 문맥 제한, 허용 단계, JSON 스키마, 출력 검증, 1회 재시도, 문맥 제안의 별도 재검토와 결과 집계를 담당합니다. `src/ai/local-ai.cjs`는 기존 Qwen3 0.6B CPU 런타임을 공유합니다. AI는 단계만 반환하며 본문·문단·XML을 생성하지 않습니다. 들여쓰기·기호 근거는 코드가 확인하고, 근거 없는 최상위 항목은 보류합니다. 재검토는 같은 모델을 이용하므로 독립적인 정확성 보증이 아닙니다.

한 번에 최대 24항목, 추론 전체 2분, 항목별 재시도·재검토 포함 30초입니다. 모델 로딩 시간은 추론 예산과 별도입니다. 실패와 미검토를 정상 완료로 표시하지 않으며, 취소 시 완료한 제안은 남습니다. 문서를 외부 AI 서버로 보내지 않습니다.

## 표와 자동 번호

- 표는 셀마다 별도 목록으로 처리하고 셀 안의 문단 수·병합·주소를 유지합니다. 일반 문단과 표 셀을 합쳐 한 번에 100개까지 저장합니다.
- HWPX의 `NUMBER` 문단 번호는 본문에 번호 문자를 삽입하지 않고 번호 정의와 참조를 복제합니다. 셀별 정의를 분리하며 원래 시작·이어가기 관련 속성과 문단 여백을 보존합니다. 번호의 실제 표시는 한글에서 계산합니다.
- 공유 자동 번호 목록 일부만 바꾸어 번호가 분리되는 경우 저장을 거부합니다. 지원하지 않는 문단이 같은 목록에 있으면 한글에서 해당 목록을 정리해야 합니다.
- `OUTLINE` 개요, 자동 글머리표, 중첩 표, 필드와 복잡한 제어 요소, 구형 HWP는 지원하지 않습니다. 직접 입력한 `-` 같은 기호는 단계 검토 대상입니다.

## 검증

실제 Qwen CPU 모델의 제한된 합성 사례에서 들여쓰기 5항목·문맥 2항목의 제안이 기대한 단계와 일치하고, 근거 부족 1항목은 보류했습니다. 이 수치는 실제 업무 문서 전체의 정확도가 아닙니다. 재현 명령은 `npm run test:structure -- --ai`이며 보유 GGUF를 사용하고 자동 다운로드하지 않습니다. 결과는 `STRUCTURE-QUALITY-1.5.0.json`에 기록합니다. 단위·화면·설치본 검증 결과는 `UPDATE-VERIFICATION.md`를 참고하세요.

설치 파일은 `release/1.5.0-ready/SsenDoc-Setup-1.5.0.exe`입니다. 로컬 빌드와 공개 게시·자동 업데이트 배포는 별개입니다.
