# 쎈doc 1.0.1 — 맞춤법 검사·문서 대조·용량 줄이기를 한곳에서

공문과 가정통신문을 보내기 전에 글을 다듬고, 문서끼리 다른 내용을 확인하고, HWPX 파일의 용량을 줄이는 Windows 앱입니다. 쎈Pick의 문서 대조와 쎈Lite의 압축 기능에 맞춤법·띄어쓰기 검사를 더했습니다.

## 이번 버전에서 바뀐 점

AI 모델 관리에서 사용하지 않는 EXAONE 항목을 없애고 **Qwen3 0.6B 한 가지만** 표시합니다. 다운로드 안내도 약 400MB로 맞췄습니다. 기존 Qwen 모델은 그대로 사용할 수 있으며 다운로드·재개·삭제·파일 직접 지정 기능은 유지합니다.

## 다운로드

| 파일 | 사용 방법 |
| --- | --- |

Windows 10/11 x64용입니다. 현재 Windows 11 장비에서 검증했으며 Windows 10 실기 테스트는 아직 하지 않았습니다. 코드 서명이 없어 SmartScreen 경고가 나타날 수 있습니다. 배포 출처와 [SHA-256 목록](https://github.com/HooniKims/ssen-doc/releases/download/v1.0.1/SHA256SUMS.txt)을 확인하세요. `latest.yml`과 `.blockmap`은 업데이트용 파일이므로 직접 실행할 필요가 없습니다.

## 1. 글을 붙여 넣고 맞춤법·띄어쓰기 교정

**텍스트 붙여넣기 → 검사하기 → 교정안 확인·적용 → 복사 또는 저장** 순서로 사용합니다. 입력창에서 직접 수정할 수 있고 실행 취소와 교정 전후 비교도 제공합니다. 아래는 1.0.1의 실제 첫 화면입니다.

![쎈doc 1.0.1 맞춤법 검사 첫 화면](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.0.1/docs/ui-home.png)

- 기본 검사에는 규칙 444개와 50,000개 빈도 단어 목록이 포함되어 있습니다. 모델 다운로드 없이 오프라인으로 동작합니다.
- 예: `회의가 됬어요. 참여할수있습니다.` → `회의가 됐어요. 참여할 수 있습니다.`
- 규칙 교정안은 한꺼번에 적용할 수 있습니다. 사전 후보와 AI 제안은 사용자가 하나씩 확인해야 하며 전체 적용에서 제외됩니다.
- 사전에 없는 단어는 고유명사나 활용형일 수 있습니다. 확정 오류로 취급하지 않습니다.
- 수정한 글은 복사하거나 TXT·HTML로 저장할 수 있습니다.

## 2. 문서 안의 글도 찾아서 수정하고 저장

**문서 불러오기**로 HWPX 또는 XLSX를 선택하세요. 문단·셀 목록에서 내용을 확인하고, 교정안을 적용하거나 직접 고친 뒤 **교정본 저장**을 누르면 새 파일로 저장됩니다. 원본은 덮어쓰지 않습니다.

![HWPX 문단을 수정하고 교정본을 저장한 화면](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.0.1/docs/ui-document-spelling.png)

50MB 이하 파일을 지원하며 한 번에 최대 100개 문단·셀의 변경을 저장합니다. 수식·보호된 셀·복잡한 필드 등은 읽기 전용입니다. 문서 페이지 위에 직접 표시하는 방식이 아니라 문단·셀 목록에서 위치와 내용을 보여 줍니다. 저장 후 한글이나 Excel에서 배치와 수식을 확인하세요. 구형 HWP/XLS, DOCX, PDF, 이미지 OCR은 지원하지 않습니다.

## 3. 문서 대조

같은 행사의 계획서·가정통신문·예산표처럼 함께 확인할 HWPX·XLSX 파일을 넣고 검사하세요. 날짜·요일, 인원, 금액, 장소, 지난 연도가 남아 있는지 등을 검토하고 원문 근거를 확인할 수 있습니다.

![예제 문서 3개에서 확인할 항목 6개를 찾은 문서 대조 화면](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.0.1/docs/ui-review.png)

**확인 완료로 표시**는 검토 상태를 바꾸는 기능입니다. 문서 내용 수정은 **직접 수정**과 수정본 저장 기능을 사용하세요.

## 4. HWPX 용량 줄이기

HWPX 파일을 추가하고 화질 또는 목표 용량을 선택한 뒤 **가볍게 저장**을 누르세요. 문서 속 이미지를 압축해 별도 파일로 저장합니다.

![예제 HWPX 이미지의 용량을 줄여 저장한 화면](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.0.1/docs/ui-lite.png)

화면의 99% 감소는 동봉 예제에서 나온 결과입니다. 실제 감소량과 목표 용량 달성 여부는 문서와 이미지에 따라 다릅니다. 저장 후 이미지 품질을 확인하세요.

## 5. 선택형 로컬 AI — 최초 1회 다운로드

> AI 맞춤법 검사는 최초 1회 모델 다운로드(약 400MB)가 필요합니다. 규칙 기반 검사는 다운로드 없이 바로 사용 가능합니다.

**1.0.1에서 다운로드하고 검증한 모델은 Qwen3 0.6B Q4_K_M 한 가지이며 실제 다운로드 크기는 약 397MB입니다.** 처음 검사할 때 안내를 보고 선택할 수 있습니다. **건너뛰기**를 누르면 기본 검사만 사용합니다. 나중에 **AI 모델 관리**에서 다시 준비할 수 있습니다.

![Qwen 한 가지만 제공하는 AI 모델 관리 화면](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.0.1/docs/ui-models.png)

- 다운로드 진행률·남은 용량·예상 시간, 일시정지·재개·재시도를 제공합니다. 완료 후 SHA-256을 확인합니다.
- 준비 후 **AI로 추가 검사**를 누르세요. CPU에서 실행하며 모든 결과는 제안으로 표시합니다. 사용자 확인 없이 적용하지 않습니다.
- **모델 삭제**로 앱에 저장한 모델을 지울 수 있습니다. 다시 필요하면 내려받을 수 있습니다.
- 방화벽 때문에 다운로드가 어려우면 **모델 파일 직접 지정** 메뉴를 사용하세요. 앱이 파일을 복사해 사용하므로 모델 삭제 후에도 직접 지정한 원본은 남습니다. 모든 GGUF 모델의 호환성을 보장하지는 않습니다.
- 작성한 글과 문서는 서버로 전송하지 않습니다. 인터넷은 모델 다운로드와 업데이트 확인에 사용합니다. 다운로드가 끝나면 검사에 인터넷이 필요하지 않습니다.

## 확인한 범위와 남은 한계

- 단위·회귀 테스트 **564개**, Playwright UI 테스트 **6개** 통과.
- 배포판에서 맞춤법·띄어쓰기 교정, HTML 저장, 문서 대조, 실제 HWPX 압축과 화면 전환을 확인했습니다.
- 실제 Qwen 파일의 다운로드·중단·재개·체크섬·CPU 추론·삭제·재다운로드·직접 지정을 검증했습니다.
- 실제 NSIS 설치·실행·제거를 확인했습니다. 이전 공개 버전에서 새 버전으로 교체하는 자동 업데이트는 아직 검증하지 못했습니다.
- 1,680자 테스트에서 기본 규칙·사전 로드부터 교정 적용까지 약 121ms였습니다. 사용자 조작·문서 불러오기·AI 시간은 제외한 이 장비의 측정값입니다.
- 작은 AI는 문장당 약 5.7~9.8초가 걸린 사례가 있습니다. 오탈자 교정을 제안했지만 `할수있어요.`의 띄어쓰기 오류를 놓친 실행도 있었습니다. 기본 규칙의 띄어쓰기 교정 테스트와 AI 정확도는 구분해야 합니다.

화면은 1.0.1 앱과 테스트용 예제 문서를 사용한 캡처입니다. 모델의 실제 다운로드·추론·삭제 전체 검증 기록은 동일한 Qwen 모델을 사용한 1.0.0의 결과이며, 이번 버전에서는 단위·UI 회귀 테스트와 배포판 실행을 다시 확인했습니다. 자세한 검증 기록은 [UPDATE-VERIFICATION](https://github.com/HooniKims/ssen-doc/blob/v1.0.1/docs/UPDATE-VERIFICATION.md), 사용 범위와 출처는 [README](https://github.com/HooniKims/ssen-doc/blob/v1.0.1/README.md)에서 확인할 수 있습니다.
