# 쎈Doc 1.2.0 — 쎈 시리즈 디자인 통일

맞춤법 검사·문서 대조·HWPX 용량 줄이기를 하나의 Windows 앱에서 사용합니다. 이번 버전은 쎈 시리즈 디자인 가이드를 적용해 세 화면의 글꼴, 색상, 메뉴, 버튼, 설정 창과 로고를 맞췄습니다.

## 달라진 화면

- 따뜻한 크림색 바탕, 흰 카드, 초록 주 버튼과 민트색 선택 표시를 사용합니다.
- 본문과 제목은 Cafe24 PRO Slim, 메뉴와 버튼은 학교안심 자연입니다. 글꼴은 설치 파일에 포함되어 인터넷 없이 표시됩니다.
- 위쪽 헤더에 쎈Doc 로고·버전·이용권·설정을 모았습니다. 모든 기능 버튼에 아이콘과 글자를 함께 표시합니다.
- 기본 창은 1280×800, 최소 창은 1024×700입니다. 작은 창에서도 설정과 이용권 창을 스크롤해 사용할 수 있습니다.
- 검사 버튼을 입력란 위에 배치했습니다. 문서 대조와 압축 결과는 상세 목록 위에서 먼저 확인합니다.

### 맞춤법·띄어쓰기 검사

글을 붙여 넣거나 HWPX·XLSX 문서를 불러와 검사합니다. 교정 항목을 확인해 적용하거나 직접 고친 뒤 글을 복사하고 TXT/HTML 또는 문서 교정본으로 저장할 수 있습니다. 문서 원본은 덮어쓰지 않습니다.

![맞춤법 검사 첫 화면](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.2.0/docs/design-spell-1280.png)

### 문서 대조

여러 학교 문서의 날짜·인원·장소·금액을 비교하고 차이를 확인합니다.

![문서 대조 결과](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.2.0/docs/ui-review.png)

### 용량 줄이기

HWPX 안의 이미지 용량을 줄입니다. 목표 용량이나 품질을 선택하고 결과를 새 문서로 저장합니다.

![용량 줄이기 결과](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.2.0/docs/ui-lite.png)

### 선택형 로컬 AI

AI 맞춤법 검사는 최초 1회 모델 다운로드(약 400MB)가 필요합니다. 규칙 기반 검사는 다운로드 없이 바로 사용 가능합니다.

첫 화면에서는 추천만 합니다. 사용자가 안내를 열고 **AI 모델 다운로드**를 눌러야 받습니다. **지금은 건너뛰기**도 가능하며 나중에 AI 모델 관리에서 받을 수 있습니다. 모델은 Qwen3 0.6B 한 가지입니다. 일시정지·재개·삭제·GGUF 직접 지정을 지원하며 AI 제안은 항목별로 확인해 적용합니다. 설치 파일에 모델은 포함하지 않습니다.

![선택형 AI 안내](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.2.0/docs/ui-ai-optional.png)

## 설치와 이용권

Windows 10/11 x64용입니다. **SsenDoc-Setup-1.2.0.exe**는 설치형, **SsenDoc-1.2.0-x64.zip**은 무설치형입니다. ZIP은 모두 풀고 SsenDoc.exe를 실행하세요. 기존 설치 식별자와 모델·설정 저장 경로는 유지됩니다. 코드 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다.

쎈 시리즈 공통 계정으로 로그인합니다. 센스쿨(@senedu.kr) 이메일이면 무료입니다. 이미 다른 쎈 앱에서 인증했다면 따로 할 일이 없습니다.

검사는 인증 없이 사용할 수 있고, 교정 적용·저장·복사·압축 저장·모델 변경은 이용권 확인 후 사용할 수 있습니다. 로그인·이용권 확인에는 인터넷이 필요하며, 오프라인 편집은 저장된 이용권의 유효기간에 따릅니다.

검사할 글과 문서는 외부 서버에 보내지 않습니다. 외부 맞춤법 API를 사용하지 않으며 기본 검사와 AI 추론은 PC에서 처리합니다. 자동 검사가 모든 오류를 잡아내지는 못합니다. 올리기 전 한 번 더 읽어보세요.

단위 테스트 591개, 소스와 배포본 UI 테스트 각각 14개를 통과했습니다. 화면 캡처는 별도 테스트 프로필·합성 문서·모의 이용권으로 촬영했습니다. [검증 기록](https://github.com/HooniKims/ssen-doc/blob/v1.2.0/docs/UPDATE-VERIFICATION.md)과 [디자인 적용 내역](https://github.com/HooniKims/ssen-doc/blob/v1.2.0/docs/DESIGN-UNIFICATION.md)을 함께 제공합니다.
