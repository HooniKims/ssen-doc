# 쎈Doc 1.3.0 — 필요한 수정만 표시

정상 표현까지 길게 나열하던 검사 결과를 줄였습니다. 사전 미등록어와 문맥 확인 안내를 제외하고, 같은 수정은 묶어서 보여 줍니다. 맞춤법·띄어쓰기 검사, 문서 대조, HWPX 용량 줄이기를 한 앱에서 사용할 수 있습니다.

## 달라진 검사

- ‘지키며’, ‘작성하신’, ‘회신해’처럼 사전에 없다는 이유만으로 표시하던 항목과 글자 유사도 추천을 제외했습니다.
- ‘안·않·로서’ 등이 있다는 이유만으로 나타나던 일반 안내를 제외했습니다.
- 같은 수정은 한 항목으로 묶고 각 위치를 이동하며 확인합니다. 목록 분류·개수·본문 강조가 일치합니다.
- ‘이 표현 무시’는 현재 글/문단의 재검사에도 유지됩니다. 새 글이나 다른 문단을 불러오면 초기화됩니다.
- 검사 본문과 설명의 글꼴을 바꾸고, 잘린 글자 조각 대신 어절 단위로 수정안을 표시합니다.

![맞춤법 검사 결과](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.3.0/docs/quiet-spelling-1280.png)

## 규정 근거와 문장 호응

공식 자료의 자체 요약 5건을 로컬 검색 자료로 넣었습니다. 한글 맞춤법 제35·42·53항, 허용 표기를 보호하기 위한 제47항 참고 자료, 문장 호응 참고 자료입니다. 관련 근거·예외·예문을 AI에 제공하고 지원 범위를 벗어난 수정은 제외합니다. 출처와 확인일은 **근거 보기**에서 확인할 수 있습니다.

일부 명확한 호응 패턴(예: ‘저의 목표는 학생들이 안전하게 귀가합니다.’)은 별도 구조 규칙으로 검사합니다. 문장 호응 제안은 전체 적용에서 제외하고 하나씩 확인해 적용합니다. 규정 전문을 탑재한 것은 아니며 모든 비문을 검사하지는 않습니다. 작은 AI는 근거를 제공해도 오류를 놓칠 수 있습니다.

![작은 창의 수정 제안](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.3.0/docs/quiet-spelling-1024.png)

## 선택형 로컬 AI

AI 맞춤법 검사는 최초 1회 모델 다운로드(약 400MB)가 필요합니다. 규칙 기반 검사는 다운로드 없이 바로 사용 가능합니다.

Qwen3 0.6B 모델은 사용자가 다운로드를 선택한 경우에만 받습니다. 건너뛰기·일시정지·재개·삭제·GGUF 직접 지정을 지원합니다. 기본 검사와 AI 추론은 PC에서 처리하고 검사할 글과 문서를 외부 서버에 보내지 않습니다. 외부 맞춤법 API는 사용하지 않습니다.

인증서를 검사하는 일부 네트워크에서는 모델 다운로드가 막힐 수 있습니다. 이번 환경에서도 해당 오류가 발생했으며, 보유한 GGUF를 직접 지정한 배포본의 추론·삭제는 확인했습니다.

## 문서 대조·용량 줄이기

여러 문서의 날짜·인원·장소·금액을 비교하고, HWPX 이미지 용량을 줄여 새 문서로 저장합니다. 문서 원본은 덮어쓰지 않습니다.

## 설치와 이용권

Windows 10/11 x64용입니다. **SsenDoc-Setup-1.3.0.exe**는 설치형, **SsenDoc-1.3.0-x64.zip**은 무설치형입니다. ZIP은 모두 풀고 SsenDoc.exe를 실행하세요. 기존 설치 식별자와 모델·설정 저장 경로는 유지됩니다. 코드 서명이 없어 Windows SmartScreen 경고가 나타날 수 있습니다.

쎈 시리즈 공통 계정으로 로그인합니다. 센스쿨(@senedu.kr) 이메일이면 무료입니다. 이미 다른 쎈 앱에서 인증했다면 따로 할 일이 없습니다.

검사는 인증 없이 사용할 수 있고, 교정 적용·저장·복사·압축 저장·모델 변경은 이용권 확인 후 사용할 수 있습니다. [검증 기록](https://github.com/HooniKims/ssen-doc/blob/v1.3.0/docs/UPDATE-VERIFICATION.md)을 참고하세요. 테스트 예문 결과가 임의의 문서 정확도를 보장하지는 않습니다.
