# 쎈doc 1.1.0 — 쎈 시리즈 공통 인증

쎈 시리즈 공통 계정으로 로그인합니다. 센스쿨(@senedu.kr) 이메일이면 무료입니다. 이미 다른 쎈 앱에서 인증했다면 따로 할 일이 없습니다.

맞춤법·띄어쓰기 검사, 학교 문서 대조, HWPX 용량 줄이기를 하나의 Windows 앱에서 사용하는 쎈doc에 공통 이용권을 연결했습니다.

## 달라지는 사용 방법

화면 오른쪽 위 이용권 버튼에서 이메일 인증번호로 로그인하세요. 교육용 센스쿨 계정은 매년 이메일을 재인증해 무료로 사용하고, 일반 계정은 90일 체험 또는 통합 이용권 코드를 등록합니다. 등록한 PC 확인·해제와 인증 진단 정보도 같은 창에서 볼 수 있습니다.

| 인증 없이 가능 | 인증 후 가능 |
|---|---|
| 글 입력·붙여넣기, 문서 열기, 맞춤법·띄어쓰기 검사 | 교정안 적용·직접 문서 수정, 교정본·TXT·HTML 저장·복사 |
| 문서 대조, 원문·차이 확인 | 수정본·대조 보고서 저장 |
| 압축할 파일 선택·확인 | 품질·목표 용량 설정, 압축 결과 저장 |
| 이미 설치한 로컬 AI로 추가 검사 | 모델 다운로드·직접 지정·삭제, 내 사전 추가 |

이번 버전부터 편집과 저장에는 인증이 필요합니다. 검사할 글과 문서는 계속 PC 안에서 처리합니다. 인증·이용권 확인에는 인터넷을 사용하며 오프라인 편집은 저장된 이용권의 유효기간에 따릅니다. 공통 계정에서 로그아웃하거나 PC 등록을 해제하면 다른 쎈 앱에도 다음 확인 때 반영됩니다.

## 설치와 로컬 AI

- 설치형: `SsenDoc-Setup-1.1.0.exe`
- 무설치: `SsenDoc-1.1.0-x64.zip`을 모두 푼 뒤 `SsenDoc.exe` 실행
- Windows 10/11 x64. 기존 설치 식별자와 실행 파일 이름을 유지합니다.
- AI 맞춤법 검사는 최초 1회 모델 다운로드(약 400MB)가 필요합니다. 규칙 기반 검사는 다운로드 없이 바로 사용 가능합니다.
- Qwen3 0.6B Q4_K_M 한 가지만 제공합니다. 모델 파일은 설치 파일에 포함하지 않습니다. AI 제안은 하나씩 확인하고 적용하세요.
- 첫 화면에서 로컬 AI를 선택 사항으로 추천합니다. **다운로드 안내**를 눌러 내용을 확인한 뒤 **AI 모델 다운로드**를 직접 선택해야 받습니다. **지금은 건너뛰기**를 누르면 추천을 숨기며, 기본 검사를 계속 쓸 수 있습니다. 나중에 **AI 검사 켜기 (선택)** 또는 AI 모델 관리에서 받을 수 있습니다.
- 코드 서명이 없어 SmartScreen 안내가 나타날 수 있습니다. 공식 출처와 첨부 SHA-256을 확인하세요.

## 확인할 점

1. 업데이트 후 설정에 1.1.0이 표시되는지 확인하세요.
2. 다른 쎈 앱에서 이미 인증한 PC는 별도 로그인 없이 이용권이 표시되고 저장이 가능한지 확인하세요.
3. 처음 쓰는 PC에서는 @senedu.kr 이메일 인증번호를 받고 PC를 등록하세요. 학교망에서도 확인해 주세요.
4. 인증 전에는 검사가 되고, 교정 적용·저장 버튼은 이용권 창을 여는지 확인하세요.
5. 로그아웃은 공통 계정에 적용되며 다른 쎈 앱의 다음 확인 때 반영됩니다.
6. 인증에 실패하면 이용권 창 아래 인증 진단 정보를 복사해 알려 주세요.

자동 검사가 모든 오류를 잡아내지는 못합니다. 올리기 전 한 번 더 읽어보세요.

검증 결과와 실제 서버에서 확인할 항목은 [검증 기록](https://github.com/HooniKims/ssen-doc/blob/v1.1.0/docs/UPDATE-VERIFICATION.md)에 구분해 기록합니다. OTP·교육용 승인·학교망 실제 인증은 모의 시험만으로 확인할 수 없습니다.
