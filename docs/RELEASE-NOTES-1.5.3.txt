쎈img처럼 업데이트를 알려 줍니다.

- 새 버전이 있으면 오른쪽 아래에 변경 내용이 담긴 알림 카드가 나타나고, 제목 오른쪽 버전에 빨간점이 표시됩니다.
- 다운로드가 끝나면 ‘다시 시작해서 적용’ 팝업을 보여 줍니다. 작업을 저장한 뒤 재시작을 선택하면 새 버전으로 바뀝니다.
- 버전을 누르면 현재 버전, 변경 내용, 마지막 확인 시각과 자동 확인 설정을 볼 수 있습니다. ‘나중에’는 알림만 닫고, ‘이 버전 건너뛰기’는 재실행 후에도 유지합니다.

자동 확인은 시작 15초 뒤와 이후 4시간마다 실행합니다. 자동 확인을 꺼도 ‘지금 확인’은 사용할 수 있습니다. 맞춤법 검사·문서 대조·용량 줄이기 화면에서 알림 상태를 공유합니다.

설치형은 사용자가 업데이트를 선택했을 때 다운로드하며, 저장 여부 확인 없이 재시작하지 않습니다. ZIP 사용자는 공식 배포 페이지에서 새 ZIP을 받아 교체합니다. 표시되는 파일 크기는 전체 파일 기준이며 실제 차등 전송량과 다를 수 있습니다.

기존 1.5.2 이하에서는 새 알림 UI가 아직 없으므로, 이번 한 번은 ‘설정 · 업데이트 → 새 버전 확인 → 업데이트 받기’로 업데이트해 주세요. 1.5.3부터 새 팝업과 자동 확인이 적용됩니다.

Windows x64 설치형: SsenDoc-Setup-1.5.3.exe
Windows x64 무설치형: SsenDoc-1.5.3-x64.zip
