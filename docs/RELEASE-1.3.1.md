# 쎈Doc 1.3.1 — 문서 전체 AI 검사 수정

1.3.0에서 AI 검사가 선택한 문단에만 실행되고, 관련 규정을 찾지 못한 문장은 실제 추론 없이 완료로 표시되던 문제를 고쳤습니다.

- **문서 전체 AI 검사**는 불러온 모든 문단·셀을 검사합니다. 텍스트 모드의 **글 전체 AI 검사**는 입력한 글 전체를 검사합니다.
- 규정 검색 결과가 없는 문장도 모델이 읽습니다. 규정 요약 밖의 제안은 별도 AI 재검토를 거쳐 **AI 검토**로 표시하며 공식 규정 근거와 구분합니다.
- 실제 검사·실패·미검사 구간 수를 표시합니다. 긴 문장은 나눠 검사하며 시간이 더 걸릴 수 있습니다. 중단하면 완료한 결과를 보존합니다.
- 문단을 이동해도 결과가 남습니다. 내용을 고치면 해당 문단의 오래된 AI 결과를 제거하고 재검사를 안내합니다.
- **기본 검사**는 모델 없이 작동하는 규칙 검사입니다. 문서를 불러온 것만으로 AI 검사가 실행되지는 않습니다.

작은 Qwen3 0.6B 모델은 여전히 오류를 놓치거나 잘못 제안할 수 있습니다. 제안이 없다는 사실은 문서에 오류가 없다는 뜻이 아닙니다. 불필요한 문체 변경은 억제하며 AI 제안은 하나씩 확인해 적용합니다. 규정 전문을 탑재한 것은 아닙니다.

AI 맞춤법 검사는 최초 1회 모델 다운로드(약 400MB)가 필요합니다. 규칙 기반 검사는 다운로드 없이 바로 사용 가능합니다. 인증서를 검사하는 일부 네트워크에서는 다운로드가 막힐 수 있으며 GGUF 직접 지정을 사용할 수 있습니다. 검사할 글과 문서는 외부 서버로 보내지 않습니다.

Windows x64 설치형은 **SsenDoc-Setup-1.3.1.exe**, 무설치형은 **SsenDoc-1.3.1-x64.zip**입니다. 기존 설치형에서는 작업을 저장하고 설정 · 업데이트에서 업데이트하세요. 코드 서명이 없어 SmartScreen 경고가 표시될 수 있습니다.
