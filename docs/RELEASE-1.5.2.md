# 1.5.2 — 실제 모델 95점 기준 통과

어미·의존 명사·문장 호응의 누락을 보완하고, 겹치는 맞춤법·띄어쓰기를 함께 적용합니다. 인용문·코드·주소는 보호하며, 문맥 판단이 필요한 제안은 개별 확인 후 적용합니다. 규칙 결과를 AI 결과로 표시하지 않습니다.

최종 고정 예시 284건 중 283건 완전 일치, **99.65점**입니다. 오류 문장·문단 171/172건, 정상 문장 오수정 0건, 공문 22건 통과, 추론 실패·미검사 0건입니다.

학교·업무 상황을 재현해 직접 작성한 합성 예문을 실제 Qwen3 0.6B Q4_K_M CPU 모델로 검사했습니다. 사용자 제공 실문서 평가, 일반 한국어 전체의 정확도, AI 단독 점수가 아닙니다. 모든 제안을 수락했을 때의 규칙+AI 통합 결과입니다.

병렬 추론·설치 파일 압축 중 시간 초과가 발생한 실행은 통과로 처리하지 않았습니다. 원시 결과와 중단 사유를 보존하고, 제품 코드·30초 제한을 바꾸지 않은 채 순차 재검증했습니다. 최종 네 세트의 소스 SHA-256은 모두 `e5e41d8aded22dcd85838e97674cf5dac4d2aec56fdb45a227403ddb620557f7`입니다.

코드 680개, 소스 화면 29개, 배포본 화면 29개 통과. 화면 시험은 모의 인증·추론을 사용하며 실제 모델 품질 시험과 구분합니다. 실제 배포 EXE, 모델 직접 지정·SHA-256·CPU 추론·삭제, 소스 대비 111개 파일 일치도 확인했습니다.

HWPX 공문 8문단, 자동 번호 6문단, 표 셀 위치·내용 보존을 한글 열기·재저장으로 확인했습니다. 파일 접근 모듈 등록에 성공했고, 원본 보존 및 재검사 변경 0건입니다. 원시 공문 구조 검사와 실제 렌더 미리보기 확인도 통과했습니다. 필드·개체 등 보호 대상 문단은 기존 제한을 유지합니다.
