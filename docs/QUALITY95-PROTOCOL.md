# 95점 통과 기준 — 구현 전 고정

평가 범위는 학교·업무 문서의 맞춤법, 띄어쓰기, 명백한 문장 호응과 공문 목록 서식입니다. 사실 확인·의미 모순 탐지·모든 한국어 문법의 정확도를 뜻하지 않습니다.

`tests/fixtures/quality95.cjs`: 오류 문장 60개, 정상 문장 30개, 여러 오류가 섞인 문단 10개, 공문 10편. 실무형 합성 문장을 실제 Qwen 모델로 검사하며 모의 응답은 품질 점수에 사용하지 않습니다. 새로 받은 실제 사용자 문서는 없습니다.

- 점수 = 기대 출력과 완전히 일치한 건수 ÷ 전체 110건 × 100.
- 점수 95 이상이고 오류 문장·복합 문단 70건의 완전 교정률도 95% 이상이어야 합니다.
- 정상 문장 오수정 0건, 공문 출력 일치 100%, 추론 실패·미검사 0건이 필요합니다.
- 기본 규칙·문맥 규칙·AI 제안을 합친 시스템 성능입니다. AI 단독 점수와 분리합니다. 사용자 수락을 가정해 적용하되 실제 앱의 확인 절차는 유지합니다.
- 이전 시험과 새 시험의 실패도 보존합니다. 반복 수정에 사용한 세트는 회귀 시험으로 기록합니다.
- 통과 직전 별도의 새 오류·정상·공문 예문을 고정하여 검증합니다. 그 결과로 수정하면 해당 세트도 회귀 시험으로 전환하고, 다음 별도 세트가 통과해야 완료합니다. 이전 실패를 삭제하거나 쉬운 문제로 교체하지 않습니다.
- 한글의 표·자동 번호·원본 보존과 실제 열기·재저장, 코드 및 소스·배포본 UI 시험도 통과해야 합니다.

## 정답 정정

1.5.1의 `의견을 찬성합니다`는 오류가 아닙니다. [국립국어원 한국어기초사전](https://krdict.korean.go.kr/jpn/dicSearch/SearchView?ParaWordNo=24812&nation=jpn)은 `…에/를 찬성하다` 문형을 제시합니다. 이전 원시 결과는 보존하고 이번에는 정상 문장 보호 사례로 포함합니다. 점수를 올리기 위한 정답 변경이 아니라 사전 근거에 따른 채점 오류 정정입니다.

원문 인용·코드·URL·전자우편·숫자는 보존 대상으로 다룹니다. 규칙만으로 확정할 수 없는 호응 수정은 사용자 선택 제안으로 유지합니다.

## 재실행

`node scripts/test-quality95-suite.cjs --run=check-20261020`처럼 매번 새 실행 이름을 사용하면 이전 결과를 보존하면서 네 세트를 순차 검사합니다. 개별 실행은 `node scripts/test-quality95.cjs --fixture=tests/fixtures/quality95-fresh-c.cjs --tag=새로운태그`입니다. 같은 결과 파일 덮어쓰기와 동시 모델 검사는 거부합니다. 실행 전후 `src` 파일의 SHA-256이 같아야 통과합니다.

실제 모델 검사와 설치 파일 압축을 동시에 실행하지 않습니다. 이번 검증 중 병렬 실행에서 발생한 시간 초과 및 중단된 부분 결과는 `_workspace/quality95/infrastructure-interruptions.json`과 각 원시 결과에 보존합니다. 이후 제품 코드를 바꾸지 않고 단독 추론으로 재검증했습니다. 사용자 앱은 원래 한 번에 하나의 AI 검사만 실행하며, 검사 시간 제한을 늘려 통과시킨 것이 아닙니다.
