# 쎈doc 1.0.2 — 이용약관 적용과 맞춤법 검사·문서 교정 개선

공문과 가정통신문을 보내기 전에 글을 다듬고, 문서끼리 다른 내용을 확인하고, HWPX 파일의 용량을 줄이는 Windows 앱입니다.

## 이번 버전에서 바뀐 점

**이용약관**
- 쎈doc 이용약관을 새로 정했습니다. 공식 배포처가 아닌 곳에 다시 올리기, 수정·개작, 설치 파일을 AI 서비스에 올려 분석·복제하게 하는 일 등은 허락 없이 할 수 없습니다.
- 설정 · 업데이트 창 아래에 저작권 표시와 [이용약관 보기]를 넣었습니다.
- 처음 설치할 때 이용약관 화면이 나옵니다.

참고: 이 약관은 1.0.2부터 적용됩니다. 함께 들어 있는 오픈소스 구성 요소는 각자의 라이선스를 따릅니다.

![설정 · 업데이트 창의 저작권 표시와 이용약관](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.0.2/docs/ui-license.png)

![설치 화면의 이용약관 페이지](https://raw.githubusercontent.com/HooniKims/ssen-doc/v1.0.2/docs/ui-installer-license.png)

**맞춤법 검사**
- 맞는 표현을 틀린 말로 바꾸던 자동 교정을 고쳤습니다. 예를 들어 "명절때"를 "명절대"로, "될뿐더러"를 "될 뿐더러"로 바꾸지 않습니다.
- 표준어로 인정된 '꺼림직하다', '오손도손', '건들다', '싫증나다'는 오류로 표시하지 않습니다. 규칙은 439개가 되었습니다.
- '갈려고', '쓸려고'처럼 다른 낱말의 활용형과 모양이 같은 표현은 자동으로 고치지 않고 확인 항목으로 보여 줍니다.
- 사전 검사에 학교 용어 목록을 넣었습니다. 가정통신문의 평범한 낱말이 '사전에 없는 단어'로 뜨는 일이 줄었습니다.
- AI 제안을 하나 적용해도 나머지 AI 제안이 남습니다.

**문서 교정·대조·용량 줄이기**
- 문단·셀을 많이 고친 교정본을 한 번에 저장합니다. 긴 문서에서 100곳을 고쳐도 시간 초과가 나지 않습니다.
- 엑셀에서 수식을 여러 칸에 채운 범위 안에 직접 입력한 숫자가 교정본 저장 중 지워지던 문제를 고쳤습니다.
- '학생 1인당 단가' 같은 금액 항목을 인원으로 잘못 비교하던 문제를 고쳤습니다.
- 문서 대조·용량 줄이기 화면에서 폴더를 고를 때 파일 선택 창이 뜨던 문제를 고쳤습니다.
- 용량 줄이기 중에 앱을 닫아도 임시 파일을 정리한 뒤 종료합니다.

**앱**
- 업데이트를 설치할 때 닫기 확인 창이 다시 뜨지 않습니다.
- 설치된 모델 파일이 손상되면 오류로 표시하고 삭제할 수 있게 했습니다.
- 교정본 기본 파일명에 저장 시각을 붙여 같은 문서를 여러 번 저장할 수 있습니다.

전체 변경 내용은 [CHANGELOG](https://github.com/HooniKims/ssen-doc/blob/v1.0.2/CHANGELOG.md)에 있습니다.

## 다운로드

| 파일 | 사용 방법 |
| --- | --- |
| [설치형 EXE · 약 184MB](https://github.com/HooniKims/ssen-doc/releases/download/v1.0.2/SsenDoc-Setup-1.0.2.exe) | 설치 안내에 따라 설치한 뒤 쎈doc을 실행하세요. 1.0.1을 설치해 쓰고 있다면 앱의 **설정 · 업데이트**에서 바로 업데이트할 수 있습니다. |
| [무설치 ZIP · 약 228MB](https://github.com/HooniKims/ssen-doc/releases/download/v1.0.2/SsenDoc-1.0.2-x64.zip) | 압축을 **모두 풀고** 폴더 안의 `SsenDoc.exe`를 실행하세요. 실행 파일만 따로 옮기면 동작하지 않습니다. |

Windows 10/11 x64용입니다. 코드 서명이 없어 SmartScreen 경고가 나타날 수 있습니다. 배포 출처와 [SHA-256 목록](https://github.com/HooniKims/ssen-doc/releases/download/v1.0.2/SHA256SUMS.txt)을 확인하세요. `latest.yml`과 `.blockmap`은 업데이트용 파일이므로 직접 실행할 필요가 없습니다.

AI 맞춤법 검사는 최초 1회 모델 다운로드(약 400MB)가 필요합니다. 규칙 기반 검사는 다운로드 없이 바로 사용 가능합니다.
