# 쎈Doc 1.5.2 — 공문 항목 정리 · 로컬 AI 교정 보완

텍스트와 HWPX의 공문 항목 번호를 미리 보고 정리할 수 있습니다. 이전 공개 버전 1.3.1 이후의 공문 기능과 맞춤법 개선을 함께 배포합니다.

- `1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮` 순서로 번호·단계를 정리합니다. 번호 누락·중복과 하위 번호 시작을 점검하고, 직접 입력한 번호는 문단 들여쓰기·내어쓰기도 교정본에 저장합니다.
- 표 안의 목록은 셀별로 처리합니다. 한글 자동 문단 번호는 자동 번호와 시작 값·문단 여백을 유지하면서 기호·단계를 정리합니다.
- 선택형 **AI 구조 검토**는 애매한 항목의 단계만 제안합니다. 제안을 확인하여 미리보기에 반영한 다음 적용합니다.
- 맞춤법·띄어쓰기의 겹치는 수정, 어미·의존 명사·일부 문장 호응을 보완했습니다. 인용문·코드·주소는 보호하며 문맥 판단이 필요한 수정은 개별 확인합니다.

## 공문 항목 정리 사용법

1. 한글에서 **HWPX로 저장**한 문서를 쎈Doc에서 불러옵니다. 텍스트를 붙여 넣어도 사용할 수 있습니다.
2. **공문 항목 정리**를 누르고 변경 전후를 확인합니다.
3. 항목 옆의 단계 선택에서 필요한 단계를 지정합니다. 애매한 항목에는 **AI 구조 검토(선택)**를 실행하고, 선택한 제안을 **AI 제안 미리보기에 반영**할 수 있습니다.
4. **변경 사항 적용**을 누릅니다. 잘못 적용했다면 **항목 정리 되돌리기**로 복원합니다.
5. 문서는 **교정본 저장** 후 한글에서 확인합니다. 텍스트는 복사하거나 TXT로 저장합니다. 원본 문서는 덮어쓰지 않습니다.

기본 항목 정리는 AI 다운로드 없이 사용합니다. 항목 번호·단계·들여쓰기 정리 기능이며 용지 여백·글꼴·결재란까지 공문 전체 규격을 맞추지는 않습니다. 자동 번호의 기존 문단 여백은 유지합니다. 개요·필드·중첩 표 등 지원하지 않는 부분은 제외 사유를 확인하세요. 구형 HWP는 HWPX로 저장해야 합니다. 한 번에 최대 100개 문단·셀을 저장하며 AI 구조 검토는 최대 24항목입니다.

## 검증 결과

실제 Qwen3 0.6B Q4_K_M CPU 모델과 규칙을 합친 고정 예시 **284건 중 283건 완전 일치(99.65점)**, 정상 문장 90건 오수정 0, 공문 22건 통과, 추론 실패·미검사 0입니다. 직접 작성한 학교·업무 상황의 합성 예문에 모든 제안을 수락한 결과로, 일반 한국어 전체 정확도나 AI 단독 점수가 아닙니다. `실무 회의에서 사업 계획을 검토되었습니다.`의 호응 오류 1건은 놓쳤습니다.

코드 시험 680개, 소스 화면 29개, 배포본 화면 29개가 통과했습니다. 화면 시험의 모의 인증·추론과 실제 모델 품질 시험은 구분했습니다. 실제 한글에서 공문·자동 번호·표 문서의 열기와 재저장, 내용·셀 위치·자동 번호 보존을 확인했습니다. 제안이 없다고 오류가 없다는 뜻은 아니므로 결과를 검토해 주세요.

## 설치와 업데이트

Windows x64 설치형은 **SsenDoc-Setup-1.5.2.exe**, 무설치형은 **SsenDoc-1.5.2-x64.zip**입니다. 기존 설치형은 작업을 저장하고 **설정 · 업데이트**에서 업데이트하세요. ZIP 사용자는 새 ZIP을 받아 교체합니다. 코드 서명이 없어 SmartScreen 경고가 표시될 수 있습니다.

AI 맞춤법 검사는 최초 1회 모델 다운로드(약 400MB)가 필요합니다. 규칙 기반 검사는 다운로드 없이 바로 사용 가능합니다. 검사할 글과 문서는 외부 서버로 보내지 않습니다.
