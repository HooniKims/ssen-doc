# 공문 항목 정리 검증 — 1.4.0

2026-10-20, Windows x64.

- `npm test`: 647개 통과. 번호 누락·중복, 계층 변경, 하위 번호 초기화, 8단계 기호, 날짜·소수 보호, 불명확한 계층 보류, 줄바꿈 보존을 포함합니다.
- 소스 앱의 전체 화면 회귀 테스트: 24개 통과. 새 공문 기능 3개 흐름과 기존 맞춤법·AI·인증·문서 대조·압축·XLSX 저장을 포함합니다.
- 최종 `release/1.4.0/win-unpacked/resources/app.asar` 대상 전체 화면 회귀 테스트도 24개 통과했습니다. 인증이 필요한 편집은 외부 모의 인증 fixture로 확인했으며 fixture는 배포 패키지에 포함되지 않습니다.
- HWPX: 원본 바이트·이미지·수정하지 않은 문단·기존 공유 서식을 보존하고, 새 문단 서식의 참조와 개수를 검증했습니다. 수정 문단의 줄 배치 캐시만 제거하며 재실행 시 추가 변경이 없습니다. 자동 번호는 제외하고 잘못된 서식 요청은 저장하지 않습니다.
- 실제 한글 COM: 앱에 포함된 가상 예제의 사본에 합성 항목 6개를 넣고 정리했습니다. 한글에서 1쪽으로 열고 다시 HWPX로 저장했으며, 전체 본문 텍스트가 재저장 전후 동일했습니다. 긴 항목은 3줄로 배치됐습니다. 모든 사용자 문서나 글꼴의 배치를 보장하는 검사는 아닙니다.
- `npm run test:ai`: 실제 Qwen CPU 추론 3개 구간이 오류 없이 완료됐습니다. 이는 실행 호환성 확인이며 AI가 모든 오류를 교정했다는 뜻은 아닙니다.
- 배포용 실행 파일: 실제 실행, 공통 인증 브리지 초기화, 기본 맞춤법 검사, 외부 네트워크 차단, 약관 포함을 확인했습니다. 실제 계정 로그인·로그아웃은 수행하지 않았습니다.
- `npm run dist`와 인증용 Chromium 네트워크 사전 검사를 통과했습니다. `verify-package.cjs`로 소스와 패키지 파일 106개 일치, CPU 전용 네이티브 모듈, 모델 미포함, 설치 파일·ZIP의 SHA-256을 확인했습니다. 산출물과 해시는 `release/1.4.0/`에 있습니다.
- 패키지의 모델 관리: 보유 GGUF 직접 지정, SHA-256 검사, CPU 추론, 관리 사본 삭제를 확인했습니다. 모델 다운로드·재개 네트워크 경로는 이번 변경에서 다시 시험하지 않았습니다.

화면 미리보기는 1280×800과 1024×700에서 확인했습니다. 최종 HWPX의 실제 줄바꿈과 정렬은 사용하는 글꼴과 한글 환경에서도 확인해야 합니다. NSIS를 사용자의 기존 설치 위에 설치하거나 GitHub 공개 릴리즈를 게시하지 않았습니다.
